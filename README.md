# AX-CPT Meta-Control Behavioral Analysis

## Setup

From the project root:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install jupyter ipykernel pandas pyreadstat matplotlib
python -m ipykernel install --user --name axcpt-env --display-name "Python (axcpt-env)"
```
Re-activating the environment later:

```bash
cd /Users/yizj/Desktop/AX-CPT/metaControl_behavioral_Inhibition
source .venv/bin/activate
```
